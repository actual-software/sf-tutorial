## Objective

By the end of this exercise you will have the four shell env vars this tutorial relies on (`FACTORY_PATH`, `ASCII_ART_PATH`, `TUTORIAL_PATH`, `ARTIFACTS_PATH`) exported in your current shell, with a recipe for re-establishing them in any fresh terminal.

## Prereqs

- [Page 00.2](./00.2-setup-foundation.md) complete: `ascii-art` rig registered, locked docs in place, 138 beads seeded, `main` pushed to GitHub. You set `ASCII_ART_PATH` in 00.2 step 1 and `TUTORIAL_PATH` / `ARTIFACTS_PATH` in 00.2 step 2.
- A working shell (`bash` or `zsh`) where you can edit your rc file or install [`direnv`](https://direnv.net/).

## Context

Every later page assumes all four vars are exported in your current shell:

| Var | Set in | Used by |
| --- | ------ | ------- |
| `FACTORY_PATH` | [00.1](./00.1-setup-foundation.md) Step 1 (`gc init factory1`) | every page that runs commands from inside the factory |
| `ASCII_ART_PATH` | [00.2](./00.2-setup-foundation.md) Step 1 (`gc rig add`) | every page that runs commands from inside the rig (01–05, H1–H4) |
| `TUTORIAL_PATH` | [00.2](./00.2-setup-foundation.md) Step 2 | derives `ARTIFACTS_PATH`; also handy when later pages reference other tutorial subdirs |
| `ARTIFACTS_PATH` | [00.2](./00.2-setup-foundation.md) Step 2 (derived from `TUTORIAL_PATH`) | every page that copies pre-authored ADRs, formulas, prompts, or scripts into your rig or pack (00.2, 02, 03, 04, 05, H1–H4) |

If you closed the terminal between sittings, those exports are gone — this page is the canonical place to re-establish them.

## Walkthrough

### 1. Confirm the four vars are set

Re-export the four paths in any fresh shell. Edit each value to match your machine:

**copy and paste**

```bash
export FACTORY_PATH="/absolute/path/to/factory1"
export ASCII_ART_PATH="/absolute/path/to/ascii-art"
export TUTORIAL_PATH="/absolute/path/to/sf-tutorials"
export ARTIFACTS_PATH="$TUTORIAL_PATH/artifacts"
```

### 2. Sanity-check the values resolved

**copy and paste**

```bash
ls "$FACTORY_PATH"                # expect: city.toml  pack.toml
ls "$ASCII_ART_PATH/docs"         # expect: current  decision-records  future
ls "$TUTORIAL_PATH"               # expect: artifacts/  hardening/  progression/  README.md
ls "$ARTIFACTS_PATH/docs/future"  # expect: 0001.ADR.ASCII.md (and 0002.ADR.TESTING.md)
```

### 3. Make the exports persistent

You will be constantly creating and closing new terminal sessions throughout this curriculum. Finding and re-exporting the four paths every time is a pain, so it is strongly recommended to drop the four lines into your shell rc (`~/.zshrc`, `~/.bashrc`) or a per-directory [`direnv`](https://direnv.net/) `.envrc`.

**copy and paste** (macOS / zsh)

```bash
cat <<EOF >> ~/.zshrc
export FACTORY_PATH="$FACTORY_PATH"
export ASCII_ART_PATH="$ASCII_ART_PATH"
export TUTORIAL_PATH="$TUTORIAL_PATH"
export ARTIFACTS_PATH="$ARTIFACTS_PATH"
EOF
```

**copy and paste** (Linux / bash)

```bash
cat <<EOF >> ~/.bashrc
export FACTORY_PATH="$FACTORY_PATH"
export ASCII_ART_PATH="$ASCII_ART_PATH"
export TUTORIAL_PATH="$TUTORIAL_PATH"
export ARTIFACTS_PATH="$ARTIFACTS_PATH"
EOF
```

Hardcoded paths are user-machine-specific and break for everyone except the tutorial author. The four env vars decouple the copy-paste commands from where you happened to clone or create things. The tutorial path in particular will evolve — when this tutorial upstreams to `gastownhall/gascity/docs/tutorials/`, the directory moves with it; only `$TUTORIAL_PATH` needs to change, and `$ARTIFACTS_PATH` follows automatically.

## Verification

**copy and paste**

```bash
echo "FACTORY_PATH=$FACTORY_PATH"
echo "ASCII_ART_PATH=$ASCII_ART_PATH"
echo "TUTORIAL_PATH=$TUTORIAL_PATH"
echo "ARTIFACTS_PATH=$ARTIFACTS_PATH"
```

**Expected output**

```text
FACTORY_PATH=/absolute/path/to/factory1
ASCII_ART_PATH=/absolute/path/to/ascii-art
TUTORIAL_PATH=/absolute/path/to/sf-tutorials
ARTIFACTS_PATH=/absolute/path/to/sf-tutorials/artifacts
```

All four lines should print absolute paths, not just `=`.

## Troubleshooting

- **One of the `ls` checks errors with "No such file or directory".** The corresponding path is wrong. Re-derive it from the page that originally set it: `FACTORY_PATH` from 00.1 Step 1, `ASCII_ART_PATH` from 00.2 Step 1, `TUTORIAL_PATH` from 00.2 Step 2.
- **Exports survive in this shell but vanish in a new terminal.** You skipped step 3 — the rc-file append. Run it now, or rely on opening new shells from a directory where `direnv` has loaded an `.envrc`.
- **`$TUTORIAL_PATH` resolves but `$ARTIFACTS_PATH` is empty.** `ARTIFACTS_PATH` is derived from `TUTORIAL_PATH`. Re-run the export so `$ARTIFACTS_PATH="$TUTORIAL_PATH/artifacts"` is evaluated after `TUTORIAL_PATH` is set.
